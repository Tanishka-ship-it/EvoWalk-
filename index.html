    100% C/C++ SIMULATION ENGINE / TCS-551

    Pure C/C++ Core
    + Thin Canvas Display

    Zero physics or AI runs in JavaScript. All Verlet physics, Graph BFS checks, Max-Heap elitism, and Genetic Algorithm evolution run natively in C++ (sim/cpp/) and stream frames to the browser over localhost:8080.

    DSA 01: SKELETAL GRAPH

    Adjacency List + BFS

    Joints are vertices, rigid bones are edges. Runs O(V+E) BFS to verify skeleton connectivity and builds anti-collapse braces.

    DSA 02: MAX-HEAP

    Binary Priority Queue

    O(1) champion lookup and O(E log N) extraction of the top 3 elites each generation without sorting the entire population.

    C/C++ FILES
    core/anatomy.hpp & dsa.hpp
    Creature Anatomy structs + MaxHeap<T> & SkeletalGraph (BFS)
    core/fitness.cpp & evolution.cpp
    Posture-Weighted Fitness + Genetic Algorithm (crossover, mutation, elitism)
    external/verlet_physics.cpp
    120 Hz Verlet physics, PD balance reflex, bone/muscle/terrain solvers
    external/http_server.hpp & main.cpp
    Localhost HTTP server bridge + --cli terminal mode
